# Brew Haven – Lesson 6 Activity 4, Option 1

Website redesigned using the supplied second visual reference as a **design direction**, not as a page background. The design uses warm cream/brown tones, organic curved shapes, editorial typography, soft shadows, café photography, and rounded cards.

The site includes multiple coffee types: Pumpkin Spice Latte, Classic Latte, Cappuccino, Americano, Mocha, and Cold Brew.

Login/Register is front-end only with no database. Submitting the form redirects to the Facebook group supplied by the requester.

Required graphics from the lesson remain included at 1080x1080, 1600x900, 600x200, and 336x280.
